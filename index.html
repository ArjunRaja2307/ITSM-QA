1. Go to jsonbin.io → Sign up (email only, no credit card) → log in
2. Click Bins → Create Bin → type {} → click Save → copy the Bin ID from the URL bar
3. Click your profile icon → API Keys → copy the Master Key
4. Open this file in Notepad → find PASTE_BIN_ID and PASTE_API_KEY → replace both → save → share the updated file with your team via SharePoint
